# 🏛️ UIU Question Bank

**The Open-Source Question Repository for UIU CSE Department.**

Building a comprehensive, high-fidelity Learning Management System (LMS) dashboard to empower students at United International University. This platform provides seamless access to past midterm exams, final exams, and solutions with a premium, minimalist user experience.

---

## ✨ Key Features

- **Modern Dashboard**: A Anthropic-inspired UI design.
- **Dynamic Course Navigation**: Effortlessly browse through a vast library of CSE courses with randomized "Top Course" discovery.
- **Integrated PDF Viewer**: High-performance document viewing powered by Apryse WebViewer for a native reading experience.
- **One-Click Batch Downloads**: Support for generating on-the-fly ZIP archives for entire course materials.
- **Responsive Experience**: Fully optimized for both desktop and mobile devices, ensuring access from anywhere.
- **Local Persistence**: Smart bookmarking and search history using local storage.

## 🛠️ Technology Stack

- **Frontend**: Semantic HTML5, Vanilla CSS3 (Custom Design System), JavaScript (ES6+).
- **Libraries**: jQuery, Apryse WebViewer, FontAwesome 5.
- **Design Language**:
  - **Typography**: Newsreader (Serif) & Inter (Sans).
  - **Palette**: Warm paper aesthetics with terracotta and charcoal accents.

## 📁 Project Structure

```text
├── css/            # Custom Design System & LMS Styles
├── js/             # Application Logic & Data Handling
├── data/           # Course Metadata (JSON)
├── WebViewer/      # Apryse SDK Assets
├── question/       # PDF Document Repository
└── index.html      # Main Application Shell
```
